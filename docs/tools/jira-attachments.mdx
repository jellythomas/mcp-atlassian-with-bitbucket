### Download Attachments

Download attachments from a Jira issue.

**Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `issue_key` | `string` | Yes | Jira issue key (e.g., 'PROJ-123', 'ACV2-642') |
| `attachment_id` | `string` | No | Optional Jira attachment ID to download exactly one attachment. |
| `as_base64` | `boolean` | No | Return image attachments as base64-encoded TextContent instead of EmbeddedResource. |
**Example:**

```json
{"issue_key": "PROJ-123"}
```

<Tip>
Downloads all attachments from the issue. Files larger than 50MB are skipped. Returns base64-encoded content.

For machine-to-machine transfers, pass `as_base64: true` to `jira_download_attachments`. Image attachments are then returned as portable base64 `TextContent` instead of `EmbeddedResource`.
</Tip>

### Get Issue Images

Get all images attached to a Jira issue as inline image content.

**Parameters:**

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `issue_key` | `string` | Yes | Jira issue key (e.g., 'PROJ-123'). Returns image attachments as inline ImageContent for LLM vision. |
